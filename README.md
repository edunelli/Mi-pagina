# Mi-Página

**Página web moderna creada con HTML y CSS**, diseñada para mostrar servicios y contacto de manera profesional y atractiva. Ideal para portafolios, negocios o proyectos personales.

## Características

- Diseño limpio y moderno, fácil de personalizar.
- Secciones:
  - **Inicio:** Bienvenida y presentación.
  - **Servicios:** Tarjetas visuales con efectos hover.
  - **Contacto:** Formulario funcional para mensajes.
- Menú de navegación sticky y scroll suave.
- Responsive: adaptable a móviles, tablets y desktop.

## Tecnologías utilizadas

- HTML5
- CSS3
